Zumbi Blocks by Adrian (AdrianKS) — play Zumbi Blocks 2 on Steam

Unofficial web revival of the original 2013 game, hosted with the author's permission.

Privacy: online play uses a direct browser-to-browser connection (WebRTC) between you and the host when it can, so the host's browser can see your IP address and you can see theirs. Add ?p2p=0 to the address to turn it off (everything then goes through the relay server). Your nickname, wave and kills are shown publicly on the leaderboard when you finish a match with the default rules. Visits are counted with Cloudflare Web Analytics (cookieless, no personal data, no tracking across sites).
